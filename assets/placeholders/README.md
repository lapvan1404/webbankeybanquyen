# Placeholder Images

## Purpose
Fallback images displayed when actual assets are missing or loading. Used across all asset types.

## Specifications
| Placeholder | Resolution | Max Size | Format |
|---|---|---|---|
| `product-placeholder.webp` | 1200 × 1200 px | 500 KB | WebP |
| `brand-placeholder.webp` | 512 × 512 px | 200 KB | WebP/PNG |
| `category-placeholder.webp` | 800 × 800 px | 300 KB | WebP |
| `banner-placeholder.webp` | 1920 × 700 px | 1 MB | WebP |

## Naming Convention
```
{type}-placeholder.webp
```
- `{type}` — the asset type this placeholder represents

## Example File Names
```
product-placeholder.webp
brand-placeholder.webp
category-placeholder.webp
banner-placeholder.webp
```
