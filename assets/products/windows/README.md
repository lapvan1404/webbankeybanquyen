# Windows Product Images

## Purpose
Product gallery images for Windows operating system licenses.

## Specifications
| Property | Value |
|---|---|
| **Format** | WebP (preferred), PNG (if transparency needed) |
| **Resolution** | 1200 × 1200 px |
| **Max file size** | 500 KB |
| **Images per product** | Exactly 4 |
| **Thumbnail** | Image 1 (`*-1.webp`) |

## Naming Convention
```
{product-slug}-{n}.webp
```
- `{product-slug}` — lowercase product name with hyphens
- `{n}` — image number (1–4)

## Example File Names
```
windows-11-home-1.webp
windows-11-home-2.webp
windows-11-home-3.webp
windows-11-home-4.webp
windows-11-pro-1.webp
windows-11-pro-2.webp
windows-11-pro-3.webp
windows-11-pro-4.webp
```
