# Promotion Banners

## Purpose

Promotional and seasonal campaign banner images.

## Specifications

| Property          | Value                                          |
| ----------------- | ---------------------------------------------- |
| **Format**        | WebP (preferred), PNG (if transparency needed) |
| **Resolution**    | 1920 × 700 px                                  |
| **Max file size** | 1 MB                                           |

## Naming Convention

```
promotion-{nn}.webp
```

- `{nn}` — two-digit sequential number starting from 01

## Example File Names

```
promotion-01.webp
promotion-02.webp
```
