# BannerDto

Represents a homepage banner returned by the API.

Fields:

- `id` (string): Unique banner identifier.
- `title` (string): Banner title.
- `description` (string): Optional banner description.
- `imageUrl` (string): Link to banner image.
- `link` (string): Destination URL when banner is clicked.
- `priority` (integer): Display order priority.
- `active` (boolean): Banner visibility state.
