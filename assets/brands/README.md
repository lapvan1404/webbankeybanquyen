# Brand Logos

## Purpose

Brand/manufacturer logo images displayed on product pages, brand listings, and filters.

## Specifications

| Property          | Value                                          |
| ----------------- | ---------------------------------------------- |
| **Format**        | WebP (preferred), PNG (if transparency needed) |
| **Resolution**    | 512 × 512 px                                   |
| **Max file size** | 200 KB                                         |
| **Background**    | Transparent preferred                          |

## Naming Convention

```
{brand-name}.webp
```

- `{brand-name}` — lowercase brand name, no spaces

## Example File Names

```
microsoft.webp
kaspersky.webp
eset.webp
```
