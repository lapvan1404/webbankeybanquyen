# Office Product Images

## Purpose

Product gallery images for Microsoft Office and Microsoft 365 licenses.

## Specifications

| Property               | Value                                          |
| ---------------------- | ---------------------------------------------- |
| **Format**             | WebP (preferred), PNG (if transparency needed) |
| **Resolution**         | 1200 × 1200 px                                 |
| **Max file size**      | 500 KB                                         |
| **Images per product** | Exactly 4                                      |
| **Thumbnail**          | Image 1 (`*-1.webp`)                           |

## Naming Convention

```
{product-slug}-{n}.webp
```

- `{product-slug}` — lowercase product name with hyphens
- `{n}` — image number (1–4)

## Example File Names

```
office-2024-home-1.webp
office-2024-home-2.webp
office-2024-home-3.webp
office-2024-home-4.webp
office-2024-pro-1.webp
office-2024-pro-2.webp
office-2024-pro-3.webp
office-2024-pro-4.webp
office-365-personal-1.webp
office-365-personal-2.webp
office-365-personal-3.webp
office-365-personal-4.webp
```
