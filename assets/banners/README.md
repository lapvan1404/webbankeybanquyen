# Banners

## Purpose
All banner images used across the storefront (homepage, promotions, campaigns).

## Specifications
| Property | Value |
|---|---|
| **Format** | WebP (preferred), PNG (if transparency needed) |
| **Resolution** | 1920 × 700 px |
| **Max file size** | 1 MB |

## Subfolders
| Folder | Description |
|---|---|
| `home/` | Homepage hero/carousel banners |
| `promotion/` | Promotional and seasonal campaign banners |

## Naming Convention
- Home banners: `banner-home-{nn}.webp`
- Promotion banners: `promotion-{nn}.webp`

## Example File Names
```
home/banner-home-01.webp
home/banner-home-02.webp
home/banner-home-03.webp
promotion/promotion-01.webp
promotion/promotion-02.webp
```
