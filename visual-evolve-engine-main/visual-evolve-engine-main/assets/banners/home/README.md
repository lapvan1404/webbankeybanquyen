# Home Banners

## Purpose
Homepage hero banner images displayed in the main carousel/slider.

## Specifications
| Property | Value |
|---|---|
| **Format** | WebP (preferred), PNG (if transparency needed) |
| **Resolution** | 1920 × 700 px |
| **Max file size** | 1 MB |

## Naming Convention
```
banner-home-{nn}.webp
```
- `{nn}` — two-digit sequential number starting from 01

## Example File Names
```
banner-home-01.webp
banner-home-02.webp
banner-home-03.webp
```
