# Category Images

## Purpose
Category cover/thumbnail images displayed on category cards and navigation.

## Specifications
| Property | Value |
|---|---|
| **Format** | WebP (preferred), PNG (if transparency needed) |
| **Resolution** | 800 × 800 px |
| **Max file size** | 300 KB |

## Naming Convention
```
{category-slug}.webp
```
- `{category-slug}` — lowercase category slug matching the URL slug

## Example File Names
```
windows.webp
office.webp
antivirus.webp
```
