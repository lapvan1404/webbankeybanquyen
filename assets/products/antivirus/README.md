# Antivirus Product Images

## Purpose
Product gallery images for antivirus and security software licenses.

## Specifications
| Property | Value |
|---|---|
| **Format** | WebP (preferred), PNG (if transparency needed) |
| **Resolution** | 1200 × 1200 px |
| **Max file size** | 500 KB |
| **Images per product** | Exactly 4 |
| **Thumbnail** | Image 1 (`*-1.webp`) |

## Naming Convention
```
{product-slug}-{n}.webp
```
- `{product-slug}` — lowercase product name with hyphens
- `{n}` — image number (1–4)

## Example File Names
```

kaspersky-standard-2.webp

```
